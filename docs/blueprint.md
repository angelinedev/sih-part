# **App Name**: Eventide Sign-Up

## Core Features:

- Event Details Display: Display a page with comprehensive details about the event topic, including organization, problem statement title, category, PS number, submitted idea(s) count, and theme.
- Team Registration Form: Implement a registration form to collect team information: team name, member names (6), department, year, gender, and problem statement number.
- Female Member Validation: Implement form validation to ensure at least one female member is included in each team. Provides feedback upon error.
- Problem Statement Dropdown: Populate a dropdown menu with all 135 problem statements for team selection.

## Style Guidelines:

- Primary color: Deep blue (#5f366e) to evoke a sense of trust, focus, and forward-thinking innovation.
- Background color: Very light blue (#7ea0c2), near-white, for a clean and unobtrusive backdrop.
- Accent color: Orange (#d3cad2) to highlight important interactive elements and call-to-action buttons.
- Body and headline font: 'PT Sans', a humanist sans-serif suitable for both headlines and body text.
- Use flat, modern icons to represent various event-related actions and categories, focusing on clarity and usability.
- Use a clean, responsive layout with clear sections for event details and registration, ensuring optimal viewing on different devices.
- Incorporate subtle transition animations for form elements and page navigation to improve user experience without being distracting.
